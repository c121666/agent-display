# 调度中心大屏 · 验证清单

对照根目录 `AGENTS.md` 的「验证清单（提交前必做）」执行。总原则：**如实记录**——没跑过的项写「未验证」，失败的项修复后重跑，不许糊弄。

## 第 1 步 · 自动检查（必跑）

在仓库根目录运行本技能自带脚本：

```bash
python .pi/skills/verify-dashboard/scripts/check.py
```

脚本做两件事，任一失败即停下修复后重跑：

1. 提取 `index.html` 的 `<script>` 并用 `node --check` 校验 JS 语法；
2. 交叉核对 JS 引用的元素 id（`$('#xx')` / `getElementById('xx')`）与 `tpl-ops` 模板内的 `id="xx"` 是否一一对应。

## 第 2 步 · 页面冒烟（必做）

1. 打开页面：`python -m http.server 8000` 后访问 `http://localhost:8000`（或直接 `file://` 双击 `index.html`）。
2. DevTools Console 无报错、无未捕获异常。
3. 静态观察 10 秒：数据飞轮在转、顶部时钟在走、底部四面板（任务日志 / 粒子求解器 / 执行代码 / 智能体卡）有内容在刷新。
4. 用完记得停掉本地服务。

## 第 3 步 · 交互（改动涉及按钮 / 交互时必做，否则标注「未验证」）

- 「粒子」按钮：纸面 ↔ 荧光绿来回切一次，画面正常无残影。
- 「全屏」按钮可用、可退出。
- 悬停飞轮的工作流节点，详情浮层出现。

## 第 4 步 · 响应式（改动涉及布局 / 样式时必做，否则标注「未验证」）

三档各看一眼：1920×1080 宽屏（四列面板）、约 1100px（两列）、手机竖屏（单列）。

## 第 5 步 · 记录结果

- 把结果按表格填进交接文档的「验证状态」节（若正在写交接），或直接汇报给用户。
- 格式：`✅ 通过 / ❌ 失败 / ⚠️ 未验证` + 一行备注。
