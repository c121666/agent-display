## 4. 关键决策与原因

| 决策 | 原因 | 影响 |
| --- | --- | --- |
| 逐步替换（Q7） | 用户定；新看板长一块换一块 | 混合期新旧并存，替换四块后仍剩飞轮 / 任务流 |
| 热力图 = git 提交次数 | 用户定语义 | 数据取 `repos[].daily[].commits`（契约映射表） |
| 热力图行成对 B+C | 整对显示防"假缺数据"观感；方块固定小尺寸后 4 行零成本 | 最多 2 对（4 行），孤行不显示，隐藏时脚注提示 |
| 监控 4 标签 + 10s 自动轮换 | 用户定交互；点击切换、无操作自动轮换 | 标签下有倒计时线 |
| 常动面板选「最近动态」 | 文本流最配打字机；全屏留一块常动 | 执行代码打字机退役，机制平移 |
| 开发统计今日口径 + 3 占位 | 用户定；先不认真做 12 项 | 占位待换真（见第 3 节） |
| 不做多 AI 工具兼容层 | 只用 pi，pi 原生读 AGENTS.md | 见前序交接 |
